# Weekly Review

A procedure the assistant follows every Sunday (or when asked for a weekly review).

## Steps

1. Read this week's notes in `STATE/journal/`.
2. For each project mentioned, update the "Status" section of its hub note with a dated line.
3. Move finished items out of `STATE/working-context.md` into the journal.
4. List open questions for Jordan, at most five, shortest first.

## Done when

Every project touched this week has a dated status line, and the working context
is under 30 lines.
